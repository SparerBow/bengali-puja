# বাংলার পূজা | Bengali Puja Companion

A Bengali cultural festival companion website covering the major Pujas celebrated in Bengal.

## About

বাংলার পূজা is designed to bring Bengali festival information into one accessible platform, including:

- Puja dates
- Bengali calendar dates
- Tithi information
- Rituals and observances
- Panjika references
- Puja preparation
- Cultural information
- Festival planning
- Future traffic and location-based features

## Published Pujas

1. দুর্গাপূজা | Durga Puja
2. লক্ষ্মীপূজা | Lakshmi Puja
3. সরস্বতীপূজা | Saraswati Puja
4. কালীপূজা | Kali Puja
5. জগদ্ধাত্রীপূজা | Jagaddhatri Puja

## Database

Database:

`banglapuja`

The project uses a calendar model that separates:

- Calendar traditions
- Calendar years
- Tithis
- Festival observances
- Ritual occurrences

This allows Gregorian dates, Bengali dates, and Panjika-based tithi intervals to be represented independently.
